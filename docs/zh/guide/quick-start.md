# 快速开始

安装 LWE 后，按以下步骤开始使用。

## 1. 准备 Steam 和 Wallpaper Engine

LWE 使用 Steam 创意工坊中的 Wallpaper Engine 内容。请确认：

1. Steam 已安装并已登录。
2. 你的 Steam 库中拥有 Wallpaper Engine。
3. Wallpaper Engine 已在本机安装。

## 2. 配置 Steam Web API 密钥

创意工坊浏览和搜索需要 Steam Web API 密钥。

1. 打开 Steam Web API 密钥官方页面：<https://steamcommunity.com/dev/apikey>。
2. 使用拥有 Wallpaper Engine 的 Steam 账号登录。
3. 创建或复制你的 API 密钥。
4. 打开 LWE。
5. 进入**设置**。
6. 将密钥粘贴到 **Steam Web API Key**。

未配置该密钥时，应用内创意工坊浏览和搜索将无法正常工作。

## 3. 浏览或导入壁纸内容

使用创意工坊界面发现内容，并在需要时通过 Steam 完成获取。LWE 能识别本地内容后，已导入或已同步的项目会出现在本地库中。

查看壁纸时，请先检查兼容性状态再应用。兼容性报告是产品功能：它用于解释 LWE 当前能运行什么、只能识别什么，以及哪些内容需要未来运行时工作。

## 4. 应用壁纸

1. 打开**本地库**。
2. 选择一张受支持的壁纸。
3. 选择目标显示器。
4. 应用壁纸。

如果桌面没有变化，请查看[故障排查](./troubleshooting.md)。当前已验证路径是 Wayland + `niri`。

## 5. 调整语言和主题

打开**设置**修改语言和主题偏好。LWE 的首发产品界面目标支持英文和简体中文。

## 首发支持预期

- 视频类壁纸是首发运行时重点。
- 场景类和网页类壁纸可能会被识别并用于兼容性报告。
- 运行时支持取决于应用显示的兼容性状态。
- 高级创作者工具、云/社区系统，以及广泛的网页壁纸运行时兼容并非首发目标。
