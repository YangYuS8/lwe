# 使用指南

本页说明 LWE 的主要工作流。

## 本地库

本地库是日常使用本地壁纸内容的入口。你可以在这里查看已识别壁纸、检查兼容性信息，并把受支持的项目应用到显示器。

Library 卡片现在会显示内容类型、兼容性等级和运行时可用性。可在已验证运行时路径上运行的视频项会标记为可运行；仅识别的场景/网页项会在打开详情面板前标明当前视频运行时不可运行。

典型本地库流程：

1. 打开**本地库**。
2. 选择一张壁纸。
3. 查看元数据和兼容性详情。
4. 将其应用到显示器，或清除当前分配。

应用、清除或恢复桌面分配后，LWE 会尽可能刷新当前选中的 Library 详情，使已分配显示器标签与 Desktop 页面保持一致。如果刷新失败，已填充的详情视图会继续保留，并以内联方式显示错误。

## 创意工坊

创意工坊功能围绕发现和获取编排设计。LWE 帮助用户查找 Wallpaper Engine 内容，理解它在 Linux 上是否可用，并把可识别内容纳入本地工作流。

创意工坊浏览需要在**设置**中配置 Steam Web API 密钥。订阅、下载和账号内容同步仍可能由 Steam 负责。

在线创意工坊结果仅用于发现内容。某个结果能在 LWE 中看到，并不表示它已经同步到本机；LWE 也不会直接下载创意工坊内容。请把**在 Steam 中打开**视为获取和订阅交接，然后在 Steam 完成同步后刷新本地创意工坊内容。

搜索结果卡片会标记推断出的运行时期望。视频结果在同步到本地后是当前唯一可运行类型；场景和网页结果可用于元数据和兼容性报告，但当前视频运行时不可运行；应用程序结果不在当前运行时范围内。

缺少 Steam Web API 密钥时，创意工坊搜索会引导你回到**设置**。设置也会尽可能区分常见 Steam 集成状态：未检测到 Steam、检测到 Steam 但缺少 Wallpaper Engine 创意工坊内容、Wallpaper Engine 可用但尚未同步本地创意工坊项目，以及本地创意工坊内容可用。

## 兼容性等级

请把 LWE 显示的兼容性信息作为判断壁纸当前是否可用的依据。

LWE 的产品模型识别常见 Wallpaper Engine 内容类型：

- `video`：首发运行时重点，也是已验证路径上当前唯一可运行类型；
- `scene`：在可获取元数据时识别；在真实支持实现并验证前，不是首发运行时目标；
- `web`：用于报告识别，不是首发运行时目标。

如果应用显示某项目不支持或处于降级状态，不应假定重新安装包即可修复。它可能超出了当前运行时范围。

## 显示器分配

LWE 是桌面应用优先的产品。预期工作流是：

1. 从本地库选择内容；
2. 选择显示器；
3. 应用壁纸；
4. 需要时清除或替换分配。

显示器发现和恢复行为取决于 Linux 会话。已验证路径是 Wayland + `niri`；其他环境在写入支持文档前需要明确验证。

## 设置

设置用于管理用户偏好和集成状态：

- 语言；
- 主题；
- Steam Web API 密钥；
- 在支持环境中的开机启动行为；
- 可见的 Steam 集成状态。

设置属于用户可见产品界面，必须同时提供英文和简体中文。

## 数据和本地状态

LWE 会在应用使用的 `lwe` 配置根目录下保存状态。贡献者不应把内部路径作为永久用户 API 写入文档，除非该路径被明确稳定化。

## 当前限制

首发版本不以以下能力为目标：

- 完整网页壁纸运行时兼容；
- 创作者工具；
- 云或社区系统；
- 高级自动化规则；
- 对未测试合成器或桌面环境的保证行为。
